만든 사이트를 GitHub에 올리기

GitHub Pages는 무료로 사이트를 계속 열어 둘 수 있는 곳입니다. 처음 한 번은 10~15분쯤 걸리고, 그 뒤로 고칠 때는 파일만 다시 올리면 됩니다.

순서

  2. GitHub 가입
  3. 저장소 만들기
  4. 파일 올리기 — 가장 많이 틀리는 곳
  5. 사이트 켜기 (Pages)

1. WMW에서 내보내기

편집기 오른쪽 위 내보내기를 누릅니다. 받는 파일은 둘 중 하나입니다.

내 사이트받는 파일올릴 것
사진 · 영상을 직접 올리지 않음index.html 한 파일그 파일 하나
사진 · 영상을 올림site-날짜.zip압축을 푼 폴더 안의 것 전부

ZIP을 풀면 이렇게 생겼습니다.

site-20261120/ ← 이 폴더 자체는 올리지 않습니다 ├─ index.html ← 올림 └─ media/ ← 올림 (폴더째) ├─ photo-1.webp └─ video-1.mp4

함께 받는 작업 파일(.json)은 나중에 고칠 때 편집기에서 여는 파일입니다. 내 컴퓨터에만 보관하고 GitHub에는 올리지 마세요.

2. GitHub 가입

  1. github.com/signup 에서 이메일로 가입합니다 (무료).
  2. 정한 아이디(사용자 이름)가 사이트 주소에 들어갑니다. 예: 아이디가 harugongbang 이면 주소는 harugongbang.github.io.

3. 저장소 만들기

  1. 오른쪽 위 + → New repository.
  2. Repository name을 정합니다. 이름에 따라 주소가 달라집니다.
    저장소 이름사이트 주소
    아이디.github.io (예: harugongbang.github.io)https://harugongbang.github.io/
    그 밖의 이름 (예: my-shop)https://harugongbang.github.io/my-shop/
  3. Public(공개)을 고릅니다. 무료 계정은 공개 저장소에서만 사이트를 켤 수 있습니다.
  4. Add a README file은 체크해도, 안 해도 됩니다. Create repository를 누릅니다.

4. 파일 올리기

  1. 저장소 화면에서 Add file → Upload files (빈 저장소면 uploading an existing file 글자).
  2. 내 컴퓨터에서 압축을 푼 폴더를 열고, 안의 것을 전부 선택합니다 (윈도 Ctrl+A, 맥 ⌘+A).
  3. 선택한 것을 GitHub 화면으로 끌어다 놓습니다.
  4. 아래 Commit changes를 누릅니다.

가장 많이 틀리는 곳

✗ 압축 푼 폴더째 끌어다 놓기 → index.html이 한 칸 안쪽에 들어가 사이트가 빈 화면(404)이 됩니다.

✓ 폴더 안에 들어가서 전부 선택해 끌어다 놓기 → 저장소 첫 화면에 index.html과 media가 바로 보여야 합니다.

"choose your files" 버튼으로는 폴더(media)를 고를 수 없습니다. 꼭 끌어다 놓기로 올리세요.

5. 사이트 켜기 (Pages)

  1. 저장소 위쪽 Settings → 왼쪽 메뉴 Pages.
  2. Build and deployment의 Source를 Deploy from a branch로 둡니다.
  3. Branch를 main, 폴더를 / (root)로 고르고 Save.
  4. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다. 눌러서 열어 보세요.

처음에는 몇 분 걸릴 수 있습니다. 404가 나오면 2~3분 뒤 새로고침하세요.

6. 고칠 때

  1. WMW 편집기 → 파일 → 작업 파일 불러오기로 보관해 둔 .json을 엽니다 (같은 브라우저라면 자동으로 이어집니다).
  2. 고친 뒤 다시 내보내기 → 4번처럼 Upload files로 다시 올립니다. 이름이 같은 파일은 덮어써집니다.
  3. 더는 쓰지 않는 사진은 저장소에 남아 있습니다. 지우려면 GitHub에서 그 파일을 열고 ⋯ → Delete file.
  4. 1~2분 뒤 사이트에 반영됩니다. 안 바뀌어 보이면 Ctrl+Shift+R (맥 ⌘+Shift+R).

7. 내 도메인 연결 (선택)

가지고 있는 도메인(예: www.myshop.com)으로 열고 싶을 때만 합니다.

  1. GitHub: Settings → Pages → Custom domain에 도메인을 넣고 Save.
  2. 도메인을 산 곳(가비아 · 카페24 등)의 DNS 설정:
    연결할 주소종류값
    www.myshop.com 같은 하위 주소CNAME아이디.github.io
    myshop.com (맨 앞 없이)A 4개185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153
  3. DNS가 반영되면(몇 분~하루) Enforce HTTPS를 켭니다.

자세한 내용: GitHub 공식 문서 — 내 도메인 설정

8. 주의할 점 · 문제 해결

  • 공개 저장소라 올린 파일은 누구나 볼 수 있습니다. 개인정보 · 작업 파일(.json)은 올리지 마세요.
  • 브라우저로 올리는 파일은 하나에 25MB까지, 한 번에 100개까지입니다. 큰 영상은 짧게 · 작게 줄이세요 (WMW 내보내기 창이 미리 알려 줍니다).
  • 사이트 안에서 예약 · 결제 · 문의 접수는 되지 않습니다. 버튼을 네이버 예약 · 카카오톡 채널 · 구글 폼 · 전화로 연결하세요 (디자인 탭 → 링크 → 빠른 입력).
증상확인할 것
404 · 빈 화면저장소 첫 화면에 index.html이 바로 보이는지 (폴더째 올리지 않았는지), Pages를 켰는지, 2~3분 기다렸는지
사진 · 영상만 안 보임media 폴더가 index.html과 같은 위치에 있는지, 폴더 이름이 media 그대로인지
고쳤는데 그대로1~2분 뒤 Ctrl+Shift+R로 새로고침
